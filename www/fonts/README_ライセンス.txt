Regular / Medium / Bold / Heavy / Black の静的 TrueType フォントを収録。
混植版「ニューゴスタイル」は、源暎エムゴ v2.0 をベースに、半角と全角の
英数字を Console Square Beta 由来の字形に差し替え、字幅と行間を調整したものです。
「ニューゴスタイル 行間調整」は、源暎エムゴの字形を使用した行間調整版です。

利用・再配布
------------
印刷物、画像、動画などの制作物に、商用・非商用を問わず利用できます。
フォントファイルを改変・再配布する場合は、SIL Open Font License 1.1 を維持し、
著作権表示と OFL.txt 全文を添えてください。由来をたどれるよう、同梱の
THIRD_PARTY_NOTICES.txt と FONTLOG.txt も一緒に保管してください。

継承する予約フォント名「源暎」「GenEi」「Source」は、許諾なく改変版の主要な
フォント名に使用できません。フォントファイル単体の販売はできません。
ライセンスの条件は同梱の OFL.txt 本文を参照してください。
